# Climatology

Aplicação .NET 8 com API RESTful, frontend Angular, e integração com banco de dados de memoria.

---

## Pré-requisitos

Antes de rodar a aplicação, certifique-se de ter instalado:

- [.NET SDK 8.0](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)  
- [Visual Studio 2022/2023](https://visualstudio.microsoft.com/) ou [VS Code](https://code.visualstudio.com/)  
- Angular(21.1.4) e Npm
- Banco de dados (no meu caso é banco de memoria, mas futuramente tenho planos de refatorar pra um relacional)  
- Git (para clonar o repositório)

---

## Rodando projeto
#### Frontend

- cd frontend
- npm install

ng serve ou npm start(rodar)

``http://localhost:4200``
#### Backend
- dotnet run
- dotnet build

``https://localhost:5001`` ou ``http://localhost:5000``
